# Rush

Rush is a local-first desktop video editor equipped with a chat-based AI agent that executes edits, cuts, and transcriptions directly from natural language prompts.

Get it here: [rush.starzz.dev](https://rush.starzz.dev/)

## Core Features

- Local-First Architecture: Video decoding, audio transcription, database operations, and search indexing run locally on your system. Raw media files never leave your computer.
- Custom AI Integration: Use your own API keys for cloud providers like OpenAI or Anthropic, or connect to a local model (such as LM Studio) for complete offline operations.
- Direct Timeline Control: Write commands in the agent chat panel, and the backend engine manipulates the multi-track timeline directly.
- Semantic Visual Search: Index keyframes locally to search and locate specific video shots using natural language queries.
